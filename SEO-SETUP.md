# Rocket Port Pro SEO setup

This package includes:
- Google-friendly title and meta description
- Canonical URL
- Robots directives
- Open Graph and X/Twitter sharing metadata
- WebSite + Organization structured data
- `robots.txt`
- `sitemap.xml`
- Semantic `<main>` landmark
- Keyword coverage focused on Rocket League players, stats, tournaments, communities, esports, creators, and directory searches

## Before publishing
1. Replace `https://rocketportpro.com/` in `index.html`, `robots.txt`, and `sitemap.xml` with your real public URL if you are not using that domain.
2. Publish the site.
3. Add the site to Google Search Console.
4. Submit the sitemap: `/sitemap.xml`.
5. Verify the site and request indexing for the homepage.
6. Add real, unique pages for players, tournaments, communities, creators, and news as those features become database-backed. Search engines can then index those individual pages.

## Important
SEO does not guarantee a particular Google ranking or immediate indexing. Search visibility improves as the site becomes public, crawlable, useful, fast, authoritative, and regularly updated.
